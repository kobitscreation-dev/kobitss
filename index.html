// ENTERPRISE_SECURITY_FAQ

Enterprise-Grade Security by Design.

Everything you need to know about remote MicroVM sandboxing, data privacy, and the 5% operator gate.

How does Kobits run without installing anything on my local computer?

Kobits executes 100% in remote isolated MicroVMs (E2B Firecracker container fleet). When you assign a mission, a dedicated microVM boots in under 150ms with its own Linux kernel, compiler toolchains, package managers, and test runners. Your local workstation requires zero dependencies and has zero host blast radius.

What is the Negative-to-Positive TDD Reproducer and why is it superior?

Traditional AI copilots guess at code fixes without proving whether the bug existed or whether their proposed fix worked. Kobits first synthesizes an automated reproduction test that fails on the current codebase (proving the defect). It applies minimal surgical code, then verifies that the test turns green and that all existing regression suites continue to pass at 100%.

How does Kobits self-heal CI pipelines and address PR reviews?

Kobits connects as a GitHub App and listens to check_run webhook events and PR review comments. When a CI build fails or a human reviewer requests adjustments, Kobits automatically reproduces the failure in a remote MicroVM, pushes a verified fix directly to the PR branch, and responds with explanatory notes.

Is my proprietary source code used to train AI models?

Strictly NO. Kobits operates on enterprise zero-data-retention (ZDR) APIs. Your code is processed in isolated ephemeral microVMs that are destroyed upon mission completion. Every action is cryptographically signed into an HMAC-SHA256 audit log for SOC2 Type II compliance.

What is the 5% Operator Gate?

Kobits is designed for 95% autonomous execution velocity with a 5% high-leverage operator review gate. Before code is merged into client repositories, human operators or tech leads can inspect the cleanroom diff, verify the 3 consensus seals (Aegis Security, Sentinel QA, Nexus Architecture), and approve the pull request with a single click.
